# 隐盾 · 纯本地加密密码管理器

> 随身密码保险库。不联网、不上传，数据只留在你自己的设备里。

一款 Android 端的本地密码管理器，单文件网页套壳打包，**安装包里没有 INTERNET 权限**——不是承诺不联网，是系统层面发不出去数据。

- 官网：https://www.yindun.de5.net
- 下载：https://www.pgyer.com/yindun-android
- 当前版本：V1.2.0（Build 4，8.51 MB，Android 7.0+）

---

## 功能

| 功能 | 说明 |
|---|---|
| 三种解锁方式 | 自定义密码、六位数字密码、图案连线；建库时选，之后随时可在设置里更换 |
| 本地加密 | PBKDF2 迭代 250,000 次派生密钥 + AES-256-GCM，每次保存使用新的随机 IV |
| 密码生成器 | 按长度与字符类型本地随机生成 |
| TOTP 两步验证 | 条目内直接显示动态验证码，支持相机扫码录入（图像仅内存解码，不落盘） |
| 中文拼音搜索 | 全拼与首字母简拼双向匹配，输入 `微信`、`weixin`、`wx` 均可命中 |
| 加密备份与迁移 | 导出 `.yindun` 私有二进制格式；支持 8 种主流密码管理器的 CSV 互导 |
| 自动锁定 | 切到后台立即上锁，回到前台需重新解锁 |
| 输错惩罚 | 连续输错逐步延长等待时间，累计次数不清零 |

## 安装

1. 手机打开下载页，或直接访问官网
2. 下载 APK 并安装（提示「未知来源应用」时选择允许）
3. 首次打开：阅读并同意协议 → 选择解锁方式 → 创建保险库

## 重要提醒

- **解锁凭据只存在于你的记忆里**，不存明文、没有备用钥匙、没有远程解密。忘记即无法恢复。
- **请定期导出加密备份**并单独保管（不要把备份只放在同一台手机上）。卸载应用、手机丢失或恢复出厂设置会一并删除本地数据。

## 隐私与权限

应用仅申请三项权限：

- `CAMERA` —— 仅用于用户主动触发的 TOTP 扫码，图像只在内存解码，不写入存储、不存相册、不上传
- `VIBRATE` —— 按键与操作反馈
- `WRITE_EXTERNAL_STORAGE`（`maxSdkVersion=28`）—— 仅在导出备份时使用

**不申请**：网络（INTERNET）、读取外部存储、通讯录、短信、麦克风、定位、读取应用列表等。

## 技术说明

- 形态：单文件 HTML/CSS/JS，通过 WebView 套壳打包为 APK
- 加密：Web Crypto API（`PBKDF2` → `AES-256-GCM`）
- 存储：WebView LocalStorage，仅本机
- 备份格式：`.yindun` 私有二进制（`[16 字节魔数][16 字节 salt][12 字节 IV][4 字节密文长度][密文]`）
- 旧版 `RJVAULT1:` 文本备份仅保留导入能力
